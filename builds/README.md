# RDPMan Builds

GitHub Actions writes Windows ZIP builds into this folder after successful builds on `main`.

- `RDPMan-latest-win-x64.zip` is the newest build.
- `RDPMan-<version>-win-x64.zip` files are versioned builds.

If no ZIP is visible yet, open the latest **Build Windows App** workflow run in GitHub Actions and wait for it to finish.
